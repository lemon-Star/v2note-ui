使用说明 (路线 2: GitHub 私有库)

1. 大类 = 顶部 Tab（对应 GitHub Issue 的 Label）。

2. 帖子 = 每个分类下的主贴（对应 Issue）。

3. 记录 = 帖子内无限追加的楼层（对应 Issue Comments）。

4. 点击右上角 GitHub 设置 填入你的私有仓库与 Token，即可实现全端私有同步。

创建新帖子 ✕
管理顶部大类 (新建 / 修改 / 删除) ✕
所有修改会实时同步到你的 GitHub 私有库 Labels
连接 GitHub 私有仓库 (Private Repo) ✕
配置后，所有帖子和追加记录将直接读写你指定的 GitHub Private 仓库 Issues。由于是私有仓库，外界任何人都无法访问，只有持有 Token 的你能在页面上读写。
Token 仅保存在你当前浏览器的 localStorage 中，不会上传到任何第三方服务器。
